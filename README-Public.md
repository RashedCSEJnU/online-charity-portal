## 🌟 About

The **Online Charity Portal** is a comprehensive web application designed to bridge the gap between charitable organizations and generous donors. Our platform provides a secure, transparent, and user-friendly environment where people can contribute to meaningful causes and participate in volunteer activities that make a real difference in communities.

### 🎯 Mission Statement

_"To create a transparent and accessible platform that connects hearts with causes, enabling everyone to contribute to building a better world."_

## 🚀 Quick Start

### **Prerequisites**

- PHP 7.0 or higher
- MySQL 5.7 or higher
- Web server (Apache/Nginx)
- Composer (for dependencies)

### **Installation Steps**

1. **Clone the Repository**

   ```bash
   git clone https://github.com/RashedCSEJnU/online-charity-portal.git
   cd online-charity-portal
   ```

2. **Set Up Database**

   - Create a MySQL database named `charity`
   - Import the database schema (check Database folder for structure)
   - Update database credentials in `inc/connection.php`

3. **Configure Environment**

   ```php
   // Update in inc/connection.php
   $db = mysqli_connect('localhost', 'your_username', 'your_password', 'charity');
   ```

4. **Install Dependencies**

   ```bash
   composer install
   ```

5. **Configure Email Settings**

   - Update SMTP settings in volunteer.php and registration.php
   - Add your Gmail app password for email functionality

6. **Launch Application**
   - Start your web server
   - Navigate to `http://localhost/online-charity-portal/frontend/`
